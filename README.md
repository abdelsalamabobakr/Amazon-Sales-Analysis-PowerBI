# 🛒 Amazon Sales & Customer Analytics Dashboard

An interactive end-to-end data analytics dashboard providing deep insights into Amazon's sales performance, customer behavior, and product profitability.

---

## 📊 Key Highlights & Metrics

| Metric | Value | Metric | Value |
| :--- | :--- | :--- | :--- |
| **Total Revenue** | $1.09B | **Total Orders** | 1M |
| **Total Profit** | $451.11M | **Profit Margin** | 41.52% |
| **Total Customers** | 1M (50K Repeat) | **Avg Spending** | $1.09K |

---

## 🔍 Dashboard Features

* **Sales Overview:** Monthly revenue/profit trends, city breakdowns, top brands (Sony, HP), and sales by marital status.
* **Customer Analysis:** Demographics (predominantly age 25–34), customer acquisition trends, and VIP tier segmentation (Bronze to Platinum).
* **Product Performance:** Revenue vs. profit correlation across 216 products, top/bottom performing items, and category treemaps.

---

## 🛠️ Tech Stack & Insights

* **Tools:** Power BI / Power Query / SQL
* **Design:** Custom Amazon Dark Mode UI (Orange & Navy)
* **Key Takeaways:** 
  * High **41.52% profit margin** across core categories (**Books** & **Fashion**).
  * Married customers account for **54.81%** of overall revenue.
